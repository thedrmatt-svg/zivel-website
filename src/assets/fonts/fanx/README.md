# FanX campaign fonts

These unmodified Latin-subset Barlow Condensed v13 WOFF2 fonts replace the
campaign's Google Fonts build-time downloads. Weights 500, 600, 700, 800, and
900 are separate normal-style files, matching the previous configuration.
DM Sans is reused from `../att/dm-sans-latin-variable.woff2`, with its license
in `../att/DM-Sans-OFL.txt`. FanX exposes the existing 400–700 body weights.

Downloaded from Google Fonts on 2026-11-04 using:
https://fonts.googleapis.com/css2?family=Barlow+Condensed:wght@500;600;700;800;900&display=swap

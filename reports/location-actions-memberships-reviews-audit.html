Review cap: Google API versus local presentation

The existing import uses Places API (New) Place Details and requests reviews. It maps all returned reviews without applying a local import slice. Google's official Place resource documentation, reviews[] states: List of reviews about this place, sorted by relevance. A maximum of 5 reviews can be returned.

The previous local display cap was four eligible reviews. It is now six for participating locations, but Google's maximum of five means the current import cannot supply a sixth. Existing five-star/content filters may further reduce the count. No API, import, storage, selection criteria, review text, summary or labels changed. Ordering is applied after filters and before the display cap; fewer than three eligible reviews of 20+ words retains original order, and short-review order and ties are stable.
